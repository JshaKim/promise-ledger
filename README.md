# 약속장부 (1단계 · 1a)

자동화 설비 현장 프리랜서가 **약속한 돈을 제때 받았는지** 혼자 기록하는 하루 마감 일지.
회사 가입 없이 쓰고, 기록은 폰 안(IndexedDB)에만 저장한다. 서버 없음, 로그인 없음.

- 약속 등록: 현장, 상대, 단가(일당/시급), 지급 방식(한 번에/매월), 계약 유형(근로/용역/모름)
- 하루 마감: 선택형 5문항(기본값 없음) + 비공개 특이사항
- 지급 확인: 전액/일부/못 받음 → `임금 체불`(근로) 또는 `대금 체불`(그 외) N일차 자동 계산
- 연락 시도: 응답 없음/있음 → 무응답 횟수, 연락 두절 일수
- 증빙: 근무·지급 기록 확인서(인쇄/PDF), 하루 마감 요약 "나에게 보내기"(제3자 시각 증거)
- 기록은 덧붙이기만 가능. 각 기록은 SHA-256으로 앞 기록과 연결되어 있어 **중간 기록**을 고치거나 지우면 상단에 "변조 의심"이 뜬다. 오기는 정정 기록으로 바로잡는다.
- **한계:** 체인만으로는 "가장 최근 기록을 지우는 것"과 "전체를 처음부터 다시 만드는 것"을 잡지 못한다(Codex 검증에서 재현). 그래서 하루 마감 때 기록번호·지문이 든 요약을 **나에게 보내** 바깥에 남기고, 증빙 탭 "예전 기록과 대조"에 붙여 넣어 확인한다. 대조는 1번부터 그 번호까지의 내용을 다시 계산해 보증하며, **그 번호 이후의 기록은 보증하지 않는다**(가장 최근에 보낸 요약으로 대조할수록 범위가 넓다).
- 기기 밖으로 **자동으로** 나가는 기록은 없다. 사용자가 직접 누른 "나에게 보내기"(요약)와 "백업 파일 저장"(전체)만 기기 밖으로 나간다.

## 실행

정적 파일이라 아무 웹 서버에서나 열린다. 로컬 확인:

```
python -m http.server 8811 -d promise_ledger
# http://127.0.0.1:8811/index.html
```

폰에서 계속 쓰려면 HTTPS 주소에 올리고 "홈 화면에 추가"해야 한다(iOS Safari는 홈 화면에 추가하지 않은 사이트의 저장 데이터를 일정 기간 뒤 지울 수 있다).

## 테스트

```
cd promise_ledger && npm test        # 계산·해시 체인 단위 테스트 (node 22)
```

## 범위 밖 (1b 이후)

동의한 사실만 클라우드로 공유해 업체별 경보를 모든 폰에 배포, 상대 확인 링크, 계약서 자동 작성, 회사 카드, 에스크로, 시세.
`core.js`의 `shareableFacts()`가 공유 경계다. 비공개 특이사항과 자유 서술은 이 함수 출력에 들어가지 않는다.
